# Hitbox expander & player overlay

**Hitbox expander & player overlay** is a universal Roblox utility with a clean, animated interface.

## Features

- Configurable hitbox expansion
- Player overlay with names, distance, health, and team-colored highlights
- Clean animated interface
- Dark and light themes
- Minimizable window and settings panel
- Five customizable keybinds
- Automatic settings persistence
- Keyless operation
